How the agents are held to account

Agents do the work. People hold the gates.

Every piece of work passes a fixed set of gates. Agents produce what each gate needs; a named person decides at the ones that matter, with the reason recorded.

Each decision, each agent run and what it cost is on the record, so you can see how every change reached production.

The gates in detail
SpecA person signs it. An agent reviews it first: is the outcome clear, does it fit one build, can every criterion be tested?
ViabilityAn agent scores it against your codebase; an engineer co-signs the score.
DesignAn agent drafts the flows and states; a person signs off.
BuildAn agent builds on its own branch, behind a feature flag. It never touches your main branch.
QAAn agent runs the tests and checks every acceptance criterion, with the flag on and off.
ReleaseA person accepts it and decides when it reaches your customers.

  1. Map it

    Agents build the automation; your people approve it at each gate. It runs on your systems, behind a flag you control.

  3. Run it and measure

    We run it with you, measure it against what it promised, and then choose the next workflow together.
